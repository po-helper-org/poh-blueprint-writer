---
id: C-2
title: Гость открывает карточку ресторана
boundary: frontend-backend
caller: Витрина
callee: Каталог UnitB
op: GET /v1/restaurants/{restaurant_id}
cards: BP-10.1, BP-2.1
---

## Запрос

| Поле | Тип | Обяз. | Где | Источник | Зачем потребителю |
| --- | --- | --- | --- | --- | --- |
| restaurant_id | string | да | path | ФТ-3 | открыть карточку выбранного ресторана |
| venue_id | string | нет | query | ИТ-4 | посчитать путь пешком от площадки билета |

## Ответ

| Поле | Тип | Обяз. | Источник | Зачем потребителю |
| --- | --- | --- | --- | --- |
| id | string | да | ФТ-3 | связать карточку с переходами и аналитикой |
| name | string | да | ФТ-3 | показать название ресторана |
| hours | string | да | ФТ-4 | показать часы работы |
| walk_minutes | integer | да | ИТ-4 | показать путь пешком от площадки |
| promo.discount | integer | да | ПТ-1 | показать блок акции со скидкой |
| promo.window_days | integer | да | ФТ-1 | показать, сколько дней действует скидка |

## Пример ответа

```json
{"id": "r-12", "name": "Сад", "hours": "12:00–23:00", "walk_minutes": 6, "promo": {"discount": 10, "window_days": 7}}
```

## Ошибки

| Статус | Код | Когда |
| --- | --- | --- |
| 404 | RESTAURANT_NOT_FOUND | ресторан вышел из акции |

## Sequence

- Витрина -> Каталог UnitB: restaurant(restaurant_id, venue_id)
- Каталог UnitB --> Витрина: карточка, блок акции
