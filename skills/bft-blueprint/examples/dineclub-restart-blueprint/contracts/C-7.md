## Запрос

| Поле | Тип | Обяз. | Где | Источник |
| --- | --- | --- | --- | --- |
| guest_id | string | да | body | ФТ-6 |
| kind | string | да | body | ФТ-16, ФТ-6 |
| event_date | string | да | body | ФТ-16 |
| discount | integer | да | body | ПТ-1 |

## Ответ

| Поле | Тип | Источник |
| --- | --- | --- |
| status | string | ФТ-6 |
| channel | string | [УТОЧНИТЬ у CPO продукта] |

## Пример ответа

```json
{"status": "sent", "channel": "email"}
```

## Ошибки

| Статус | Код | Когда |
| --- | --- | --- |
| 409 | UNSUBSCRIBED | гость отписан — касание не уходит (ФТ-6) |
| 422 | NO_CHANNEL | у гостя нет ни email, ни телефона [УТОЧНИТЬ у CPO продукта] |

## Sequence

- Триггеры касаний -> Email / SMS: touch(guest_id, kind, event_date, discount)
- Email / SMS --> Триггеры касаний: status, channel
