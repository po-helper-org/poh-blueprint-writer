boundary: external
caller: Приложение-сканер
callee: TeamA
op: POST /v1/tickets/{barcode}/verify
cards: BP-15.1, BP-16.1
---

## Запрос

| Поле | Тип | Обяз. | Где | Источник |
| --- | --- | --- | --- | --- |
| barcode | string | да | path | ФТ-1 |
| restaurant_id | string | да | body | ФТ-1 |

## Ответ

| Поле | Тип | Источник |
| --- | --- | --- |
| status | string | ФТ-1 |
| discount | integer | ПТ-1 |
| reason | string | ФТ-15 |

## Пример ответа

```json
{"status": "valid", "discount": 10, "reason": null}
```

## Ошибки

| Статус | Код | Когда |
| --- | --- | --- |
| 404 | TICKET_NOT_FOUND | штрихкод не найден у Acme Tickets |
| 409 | ALREADY_USED | билет уже дал скидку (ФТ-1) |
| 422 | WINDOW_EXPIRED | с мероприятия прошло больше 7 дней (ФТ-1) |
| 422 | TICKET_RETURNED | билет возвращён или мероприятие отменено (ФТ-15) |

## Sequence

- Приложение-сканер -> TeamA: verify(barcode, restaurant_id)
- TeamA -> Acme Tickets: статус билета(barcode)
- Acme Tickets --> TeamA: ticket_status, event_date
- TeamA -> Хранилище билетов: отметки скидок по barcode
- Хранилище билетов --> TeamA: used
- TeamA --> Приложение-сканер: status, discount, reason

## Цепочка

| Шаг | Кто | Вход | Что делает | Выход |
| --- | --- | --- | --- | --- |
| 1 | Acme Tickets | barcode | отдаёт статус билета и дату мероприятия | ticket{ticket_status, event_date} |
| 2 | Хранилище билетов | barcode | отвечает, давал ли билет скидку | used |
| 3 | TeamA | ticket.ticket_status, ticket.event_date, used | проверяет: активен, не использован, ≤ 7 дней | status, reason |
| 4 | TeamA | status, barcode, restaurant_id | при «валиден» помечает билет «использован» и считает скидку | discount |
