---
id: C-6
title: Подключённый ресторан попадает в каталог участников
boundary: service-service
caller: DineClub
callee: Каталог UnitB
op: POST /v1/restaurants
cards: BP-1.1, BP-2.1
---

## Запрос

| Поле | Тип | Обяз. | Где | Источник |
| --- | --- | --- | --- | --- |
| partner_id | string | да | body | ФТ-19, извне: ID партнёра в DineClub |
| name | string | да | body | ФТ-3 |
| address | string | да | body | ФТ-3 |
| hours | string | да | body | ФТ-4 |
| city | string | да | body | [УТОЧНИТЬ у DineClub] |

## Ответ

| Поле | Тип | Источник |
| --- | --- | --- |
| restaurant_id | string | ФТ-3 |
| rating | number | НФТ-2 |
| published | boolean | ФТ-4 |

## Пример ответа

```json
{"restaurant_id": "r-12", "rating": 4.7, "published": true}
```

## Ошибки

| Статус | Код | Когда |
| --- | --- | --- |
| 422 | HOURS_MISSING | нет часов работы — в каталог не публикуется (ФТ-4) |
| 409 | PARTNER_EXISTS | ресторан уже в каталоге |

## Sequence

- DineClub -> Каталог UnitB: restaurant(partner_id, name, address, hours, city)
- Каталог UnitB -> Справочник рейтингов: рейтинг(name, address)
- Справочник рейтингов --> Каталог UnitB: rating
- Каталог UnitB --> DineClub: restaurant_id, rating, published

## Цепочка

| Шаг | Кто | Вход | Что делает | Выход |
| --- | --- | --- | --- | --- |
| 1 | Справочник рейтингов | name, address | отдаёт рейтинг из квартальной выгрузки (НФТ-2) | rating |
| 2 | Каталог UnitB | partner_id, address, hours, rating | заводит участника, считает площадки рядом | restaurant_id, venues |
| 3 | Каталог UnitB | hours, restaurant_id | публикует, если часы работы есть | published |
