## Запрос

| Поле | Тип | Обяз. | Где | Источник | Зачем потребителю |
| --- | --- | --- | --- | --- | --- |
| venue_id | string | нет | query | ФТ-3 | отобрать рестораны у площадки активного билета |
| filters | string | нет | query | ФТ-11, ИТ-7 | сузить список под компанию гостя |
| limit | integer | нет | query | ИТ-3 | показать на полке столько ресторанов, сколько помещается |

## Ответ

| Поле | Тип | Обяз. | Источник | Зачем потребителю |
| --- | --- | --- | --- | --- |
| items | array | да | ФТ-3 | показать полку ресторанов |
| items.id | string | да | ФТ-3 | открыть карточку выбранного ресторана |
| items.name | string | да | ФТ-3 | подписать ресторан на полке |
| items.walk_minutes | integer | да | ИТ-4 | показать, сколько идти пешком |
| items.rating | number | нет | НФТ-2 | поставить лучшие рестораны выше |
| items.discount | integer | да | ПТ-1 | показать размер скидки на полке |
| total | integer | да | ИТ-3 | показать, сколько всего участников |

## Пример ответа

```json
{"items": [{"id": "r-12", "name": "Сад", "walk_minutes": 6, "rating": 4.7, "discount": 10}], "total": 48}
```

## Ошибки

| Статус | Код | Когда |
| --- | --- | --- |
| 404 | VENUE_NOT_FOUND | площадки нет в каталоге — витрина показывает полный список (ФТ-3) |

## Sequence

- Витрина -> Каталог UnitB: restaurants(venue_id, filters)
- Каталог UnitB --> Витрина: items, total

## Цепочка

| Шаг | Кто | Вход | Что делает | Выход |
| --- | --- | --- | --- | --- |
| 1 | Каталог UnitB | venue_id, filters | отбирает участников акции у площадки, без радиуса | candidates{id, name, walk_minutes} |
| 2 | Каталог UnitB | candidates, filters | ранжирует: ближние × рейтинг | items{id, name, walk_minutes, rating, discount}, total |
