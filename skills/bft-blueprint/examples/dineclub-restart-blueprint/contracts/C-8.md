## Запрос

| Поле | Тип | Обяз. | Где | Источник | Зачем потребителю |
| --- | --- | --- | --- | --- | --- |
| event | string | да | body | ФТ-9 | понять, какое действие совершил гость |
| stage | string | да | body | ФТ-9 | отнести событие к этапу воронки |
| utm | string | нет | body | ФТ-9 | понять, из какого письма пришёл гость |
| ticket_id | string | нет | body | [УТОЧНИТЬ у UnitB] | связать события одного гостя в одну воронку |

## Ответ

| Поле | Тип | Обяз. | Источник | Зачем потребителю |
| --- | --- | --- | --- | --- |
| accepted | boolean | да | ФТ-9 | понять, что событие принято в воронку |

## Пример ответа

```json
{"accepted": true}
```

## Ошибки

| Статус | Код | Когда |
| --- | --- | --- |
| 422 | UNKNOWN_EVENT | событие не из воронки «билет → ресторан → скидка» [УТОЧНИТЬ у UnitB] |

## Sequence

- Витрина -> Аналитика: event(event, stage, utm, ticket_id)
- Аналитика --> Витрина: accepted
