# Системные требования: Скидка по билету

Два контракта из решения TO-BE ADR: `ticket-validation` (K1) и `discount-applied-event`
(K2). Источники известны для всех параметров, кроме признака «билет уже использован»
и лимитов скидок — по ним `[УТОЧНИТЬ]` и вопросы Q1–Q3.

## Контракты

| ID | Контракт | Потребитель | Данные контракту | Источник параметров | Преобразования |
| --- | --- | --- | --- | --- | --- |
| K1 | ticket-validation | сервис скидок | ticket_number, event_date, partner_id; ответ: validation_result | ticket_number, event_date → Продажа билетов / API билетного оператора / поля external_id, event_date; partner_id → Приложение / профиль ресторана / поле partner_id; validation_result → Скидки / логика валидации / вычисляется | нормализация номера билета (external_id → ticket_number); проверка даты мероприятия не позже текущей; вычисление validation_result = валиден и не использован |
| K2 | discount-applied-event | каталог акций | promo_code, discount_amount | promo_code → Каталог акций / база каталога / поле promo_code; discount_amount → Скидки / логика скидки / вычисляется из процента и чека | вычисление скидки: процент акции × сумма чека; нормализация процента из строки «15%» в число |

## AS-IS

| ID | Как устроено сейчас | Что меняется |
| --- | --- | --- |
| A1 | Билеты: API билетного оператора отдаёт external_id и event_date по каждому билету; признак «уже использован» — [УТОЧНИТЬ: что есть в Продаже билетов] | для K1: локальный учёт использованных билетов, если у оператора признака нет (I1) |
| A2 | Каталог акций: promo_code и процент скидки по каждой акции; процент хранится строкой «15%», не числом; лимиты применений — [УТОЧНИТЬ: что есть в каталоге] | для K2: процент числом (I2); фиксация применения скидки на номер билета (I3) |

## Изменения

| ID | Изменение | Причина |
| --- | --- | --- |
| I1 | локальный учёт использованных билетов в сервисе скидок (запись номеров) | закрывает параметр «не использован» контракта K1, если у оператора признака нет |
| I2 | хранить процент скидки числом, не строкой «15%» | вычисление discount_amount контракта K2 без разбора строк |
| I3 | фиксация применения скидки на номер билета (запись в каталоге применений) | лимит «одно применение на билет» для K2 — если такой лимит есть (Q2) |
