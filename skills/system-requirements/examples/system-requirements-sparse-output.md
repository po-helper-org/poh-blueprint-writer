# Системные требования: Лояльностьcafes

Входных данных для документов недостаточно: ни одного контракта, ни одной системы,
ни одного владельца данных. Требования из догадок вреднее их отсутствия —
сначала вопросы.

## Открытые вопросы

1. PO — какие системы затрагивает программа лояльности (касса, мобильное приложение, CRM)?
2. PO — какие контракты между ними уже есть или планируются: события покупок, справочник участников, начисление баллов?
3. PO — кто владелец данных об участниках программы и их покупках?
4. PO — какие данные уже лежат в этих системах, а какие придётся создавать?
5. PO — есть ли существующая документация контрактов (API-спеки, схемы событий), которую взять как вход?
