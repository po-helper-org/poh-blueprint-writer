# ADR: Лояльностьcafes

Входных данных для ADR недостаточно: ни одной системы, ни одного интеграционного
требования, ни одного владельца. Выбор архитектуры из догадок вреднее вопроса —
сначала вопросы.

## Открытые вопросы (в «Вопросы» «Карты», «Где» — V0)

- Какие системы затрагивает программа лояльности: касса, мобильное приложение,
  CRM, процессинг? — PO.
- Какие интеграции уже есть между ними и что приходится дорабатывать? — PO.
- Какие ограничения известны: объём сети, пиковые часы, требования к скорости
  начисления баллов? — PO.
- Кто владельцы систем и кто согласует архитектурные решения? — PO.
- Есть ли ADR или документация прошлых интеграций для входа? — PO.
