# План релиза: Скидка по билету

Раскатываем фичу «Скидка по билету» на сервис сканирования билетов и базу каталога акций
(миграция). Из входа неизвестны: исполнитель миграции, выдающий доступы QA, согласующий
окно релиза, утверждающий STAGE → PROD — эти шаги помечены «требует ответа».
