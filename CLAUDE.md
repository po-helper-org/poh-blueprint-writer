# Правила работы в репозитории

## Каждое обращение — сначала Issue, потом исполнение

1. Получил обращение (в том числе пришедшее посреди другой работы) — **первым делом** заведи Issue в этом репозитории: проблема, что нужно, критерии приемки. Названия заказчиков и продуктов из скриншотов в Issue не раскрывай.
2. Только после этого берись за исполнение. PR ссылается на свои Issue (`Closes #N`).
3. Перед ответом по итогам сверь чат: у каждого обращения есть Issue, и каждое либо исполнено, либо явно отложено.
