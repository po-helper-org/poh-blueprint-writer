## Использование

```
/bft-reconcile <epic>-blueprint [--source <путь к БФТ>]
```

## Что делает

1. Запускает `./blueprint.py reconcile` в проекте: матрица «требование БФТ → где на карте → расхождение → статус».
2. Каждое «нет на карте» — возвращает работу на карту или записывает строку «Расхождения с требованиями».
3. Проверяет «покрыто» по сути: карта делает не то, что в БФТ, — тоже строка реестра.
4. `./blueprint.py lint`, повторная сверка до нуля «нет на карте», `./blueprint.py build`.

Правила — `../skills/bft-reconcile/SKILL.md`.
